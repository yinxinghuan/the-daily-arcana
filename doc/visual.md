# The Daily Arcana 视觉规范

## 视觉命题

- 每日抽取一张博物馆藏品般的手绘大阿卡纳，将玩家身份自然嵌入牌面而非贴入照片框。
- 22 张牌共享古典塔罗系统：羊皮纸、暗紫阴影、旧金描边、灰粉与暗青点色、平涂水粉和轻微纸张颗粒。

## 图片构图与身份

- 输出固定 1024×1024；金色新艺术边框贴齐四边，内部场景完整填满方形画布，不出现外部留黑、相框或 UI。
- 人物牌有头像时，参考图 1 是完整 `SUBJECT A`。保留可见脸或无脸结构、眼形与眼色、头发或材质、轮廓、服装、颜色、图案、配件和遮挡；仅把渲染技法转成平涂水粉。
- 非人、蒙面、罩布、无脸或物体主体不得被人类化、揭面、换装或替换；参考未显示的脸、皮肤、头发和四肢不得补画。
- 无人物牌或无头像时不伪造玩家肖像；除底部罗马数字牌外不生成其他文字。

## UI 与反馈

- 主界面使用深紫黑、旧金、米色牌面与克制粉色高光；功能图标统一 SVG。
- 抽牌后即时进入绘制状态；媒体失败明确显示错误并允许恢复，不伪造完成牌面。
- 平台内 390×844 与 320×568 均以无访客栏构图验收；外部访客栏只检查覆盖后仍可操作。

## 验收样本

- 真人人物牌需保留发型、眼镜、脸型、服装与配饰，同时读作同一套塔罗水粉画。
- 无脸罩布人物牌需保持眼孔、罩布材质和缺失四肢，不出现皮肤、脸或替代人物。
- 无参考牌需验证方形满版边框、牌面主体和罗马数字，无多余可读文字。
